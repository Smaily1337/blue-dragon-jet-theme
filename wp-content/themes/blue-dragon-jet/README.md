# Blue Dragon Jet - Custom WordPress Theme

Oficjalny, dedykowany motyw WordPress dla Blue Dragon Jet (Europejskiego Producenta Wdmuchiwarek Światłowodowych).

## Funkcje
- Pełna obsługa katalogu maszyn (CPT `machine`, taksonomie rur, kabli, napędów)
- Dedykowany, responsywny build mobilny (`front-page-mobile.php`)
- Karuzela powiązanych maszyn z autoplay i touch-swipe na stronach produktowych
- Integracja z Asystentem AI 24/7 (Dragon AI)
- Wielojęzyczność (PL, EN, DE) z automatyczną detekcją
- Zoptymalizowany pod Core Web Vitals i urządzenia mobilne

## Integracja AI Chat Widget
W folderze `_companion-mu-plugins/` znajduje się wtyczka `bdj-ai-chat.php`, którą należy umieścić w `wp-content/mu-plugins/`.
